# 网页 MVP 现场演示脚本（本地已走通；公网部署待授权）

对应总方案 §2 建议现场故事。所有时间按**真实经过时间**推进，不压缩车程；需要“正在路上/正在店里”的画面时，用提前正常出发的演示账号，而不是加速。

## 0. 演示前准备（T-40 分钟起）

| 时间 | 账号 | 动作 | 目的 |
|---|---|---|---|
| 前一天或 T-2h | `demo_road`（演示账号，明确是演示用户） | 注册 → 领养一只原创伙伴 → 入住（勾选公开动态）→ 种菜/收获/交居民订单攒够旅费 | 旅费只能靠正常玩法获得，不后台加币 |
| T-10 分钟 | `demo_road` | 出发去「海边咖啡馆」（步行 6 分钟 + 店内 20 分钟 + 步行 6 分钟） | 现场第 3–5 分钟时它正好在店里；地图上有音符 |
| T-5 分钟 | 观众用新手机 | 打开首页，确认 live 标识、HTTPS | — |

设备：两台手机（或一台手机 + 一个桌面窗口），各自独立登录；不要两个账号共用浏览器 cookie。

## 1. 现场流程（约 5 分钟讲解，可中途停）

1. **注册**（新观众账号 `guest_x`）：用户名 + 密码 → 自动进入「建立专属伙伴」。说明：每个账号一只专属伙伴。
2. **建立伙伴**：上传自己的宠物照片（服务器去掉位置等元数据，私有存储），或领养一位原创伙伴（同一位只属于一个家庭——可以现场让两台手机同时点同一位，只有一台成功）。
3. **接待与叮嘱**：写一句“叫我姐姐就好。它最喜欢那条蓝色的毯子。它不喜欢被抱。”→ 整理成三条便笺，逐条选“交给 TA / 只留在这里 / 不保存”与用途 → 确认。
4. **入住**：选择是否公开旅行动态 → 进家，看到“姐姐，我到家啦。”与刚交代的物件；菜园里种下欢迎作物（3 分钟成熟），钱包有 20 旅费见面礼。
5. **串门偷菜**：切到 `demo_road`（宠物在外，菜园没人守）→ 在「串门」里进 `guest_x` 的家：宠物在家守着，偷不到（“被发现啦”）。再反过来用 `guest_x` 去 `demo_road` 家摘一颗 → 进仓库；解释每批作物全体访客共享上限、同一批每人一次、主人可以巡院 10 分钟。
6. **凑旅费**：仓库 → 集市：卖给杂货铺，或交居民订单（出价更高，每单一次）。说明：玩家之间的挂牌交易没开放，这里是 NPC。
7. **出发**：旅途 → 出发站 → 海边咖啡馆（旅费 8，往返约 32 分钟）。地图上出现步行路线、宠物位置与 ♪ 音符。
8. **一起听**：点 ♪ → 面板显示“TA 在 1:40 / 2:30”→「跟着 TA 听」对齐到同一进度；「和 TA 一起暂停」是共同控制（另一台设备同时控制会提示“另一台设备正在控制”）。
9. **寻味**：路上点「到香港后，让 TA 挑一家」→ 推荐卡分开显示品质证据 / 口味匹配 / 本次价值 / 证据把握，说明“演示资料，不是真实口碑”→「让 TA 改去这家」：行程版本 +1，旧推荐标“待复核”，交通时间不变。
10. **到店**（切到 `demo_road`，它此时在店里）：选座、点游戏饮品、拍合影（原创插画明信片，不是真实照片）、和店里居民打招呼（触发「咖啡馆小侦探」，勋章进回忆柜）。
11. **通讯与动态**：通讯里收到明信片与冒险故事；离店后星球圈出现 `demo_road` 的真实到访动态（主人入住时同意公开）→ 用 `guest_x` 以宠物或主人身份评论、点赞、关注。
12. **带回东西**：回家后回忆柜出现明信片、共同听看的回忆（实际同步收听满 30 秒才有）、勋章；长途（澳门轮渡/东京航班）会带回稀有种子，可种进菜园。

## 2. 可能的现场状况与说法

| 状况 | 处理 |
|---|---|
| 浏览器拦截自动播放 | 面板会提示“浏览器拦下了播放，请再点一次”，再点一次即可 |
| 网络中断 | 写操作带幂等键，重试不会重复扣费/重复发货；页面显示错误与重试按钮 |
| 推荐只有 1–2 家 | 如实说明“只有 N 家符合条件，不硬凑”（营业时间/预算会排除候选） |
| 有人问“真实班次吗” | 演示线路按真实经过时间推进，但不是核验过的班次；动物世界承运人是原创身份 |
| 有人问“地图是真实底图吗” | 当前是示意地图；高德/Google 需要 key 与授权，能力显示“未配置” |

## 3. 不在演示里声称的事

- 没有接入真实地图底图、真实时刻表、语言模型接待、生图英雄照、Jev 判断器；这些能力在 `/api/v1/web/meta` 显示 `not_configured` / `disabled`。
- 没有真实商家菜单与口碑；寻味资料是演示小样本。
- 没有真实原型档案领养；领养池是原创伙伴。
- 没有玩家市场；集市只有 NPC 杂货铺与居民订单。
