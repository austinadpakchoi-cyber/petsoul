# PetSoul 后端并行工作包与窗口提示词

更新：2026-09-22。建议：**1个总集成窗口＋3条可独立开发线＋1个独立验收角色**。人手少时验收由当前CTO窗口承担，共4个主要编码窗口。由用户决定各包给Claude、Codex或DeepSeek，不按模型名称固定模块。

本文件是可分发的工作包，不是源码已分派或已经完成的声明。当前Claude仍登记持有后端广泛范围；其任务先缩小到具体文件，再允许其他窗口同时修改对应源码。用户不必另建工作副本或工作目录。

## 1. 为什么现在可以并行

已有基础足够分工：0.4.0的家庭、多宠、居民、真实交通与独立worker已出现。新的工作应按独立边界拆开，不再让同一个窗口同时负责基础设施、Agent、业务接入和全部验收。

当前具体证据：

- 基础设施子任务用实际WebTaskQueue和临时SQLite复现“过期running不被重新领取”和“superseded被旧complete覆盖”；还用两个计量实例复现先allow后record可超过一次额度。详见基础设施报告，均不等于生产故障复现。
- Runtime/Brain核对确认目前行动主要由画像加权与稳定随机选择，模型主要用于表达；纯心跳与有限模型提案可以分开实现。
- QA核对发现真实验收脚本部分步骤只保存观察值，没有强制断言；“模型路径”接受模板响应，工资检查也需补“恰好一次”的判定。不能仅看到脚本跑完就认定全部通过。
- 旧可视化看板是12:45快照，不能直接当作当前剩余任务。新任务进度以各窗口最新日志、代码和验收为准。

本轮已经用3个子agent并行核对上述问题，源码尚未修改。后续正式实现按下表领取。

## 3. 开工与交接顺序

1. **保留正在跑的真实验收。** 当前18763的自然时间打工结束点为北京时间次日01:04；工资恢复结果尚需实际判定，不改时钟、不提前宣布通过。
2. 原Claude缩小源码占用，接受[最小协作接口](RUNTIME-PARALLEL-CONTRACT-v0.1.md)。这只需先处理接口/范围，不必等自然时间打工完全结束才允许其他窗口工作。
3. A/B/C并行开发，Q并行写判定器和外部可观察验收；I同时处理UoW/outbox、现有业务桥接和真实验收收尾。
4. A/B/C每做完一个小切片就交接：先接口和核心规则，再恢复边界。不要全部做完才让I接。
5. I按“工作结束→工资一次→事件outbox→家庭消息”第一条链路接入，然后到站、回复和心跳决策。一次只接一批共享入口变化。
6. Q检验真实组合后的结果。单个包通过不代表全链路通过，文档完成也不等于接入运行。
7. 确定版本后才做服务器发布，发布权不因领取某个包而自动获得。

同副本源码变化可能被reload进程自动加载。执行前I确认哪些验收进程会加载工作树文件，关闭自身自动reload或固定其读取代码版本；不能让各窗口自行重启18763。不要假设“没重启”就一定不受改动影响。

各包独立测试可使用自己的最小目标表和注入接口，DDL作为交接稿交I。不要提前写入自动发现的迁移目录。测试中使用替身是为了验证机制；正式产品接入仍必须用真实持久状态和已授权的供应商。

## 4. 共同黑板：继续用现有日志

沿用 `docs/coordination/WINDOW-<id>.log.md` 与 [通用启动提示词](WINDOW-START-PROMPT.md)，不安装新的协作平台。每个窗口仅追加自己的日志。

领取时额外登记：`package=I|A|B|C|Q`、接口版本、精确文件、依赖、验收ID。扩大范围先SCOPE_CHANGE；冲突只停止冲突部分，继续已领取的独立工作。

建议状态：READY → CLAIMED → LOCAL_VERIFIED → READY_TO_INTEGRATE → INTEGRATED → ACCEPTED。它们放在各自记录里，不让五个窗口同时编辑一张状态表。I负责汇总，只读其他日志。

READY_TO_INTEGRATE交接至少包含：

```text
包名 / 窗口ID / 接口版本：
实际修改文件与SHA256：
新增字段与迁移需求：
消费者调用方式、兼容范围、失败语义：
验证命令 / 结果 / 隔离环境：
还没接入的入口与未验证行为：
需要I修改的准确文件和函数：
是否停止写入并释放：
```

同工作树中的代码已经对所有窗口可见，不做分支cherry-pick。不允许git add .、reset、clean、stash、擅自pull/切分支/整仓提交。各包测试不读取实际用户库，不继承含供应商密钥的真实验收配置，不争用公共端口。

接口变化在自身日志登记 `CHANGE_REQUEST`，由I回应并更新契约；不要通过直接改其他包文件“帮忙修类型”。报告只留必要ID与去敏结果，不写原始口令、Token或私人倾诉。
