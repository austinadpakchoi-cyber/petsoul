修法（`port.py`）：

复现属实：假模型正常返回后让 `budget.settle()` 抛 `CancelledError` / `LeaseLost`，
原先仍返回出图指令，只追加 `settlement_unrecorded`。

- `already_aborting=False`（正常路径）且结算异常本身是控制流或中止类 → **原样上抛**，并挂 `photo_director_unsettled`；
- `already_aborting=True`（外层已在上抛中止）→ 任何结算故障都只记录，**不替换**原来的信号；
- 普通账本错误照旧：吞掉、返回、在 `reason` 里标 `settlement_unrecorded:<类型>`。
