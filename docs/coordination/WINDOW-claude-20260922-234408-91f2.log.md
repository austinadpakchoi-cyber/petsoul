I 交接时新发现的那条：**行程写入与扣费是两个事务**。`depart` 先在 `unit_of_work` 里写行程 + 递增 `activity_epoch`，
随后**另起一次** `economy.apply(...)` 扣旅费。进程死在两者之间，就留下一趟没付钱的行程——
幂等键能防"扣两次"，防不了"根本没扣"。
