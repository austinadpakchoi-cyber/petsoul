### 2. 整体设计方向

**用户打开的是自己和宠物共同生活的家。**它能让人马上明白：“它在外面看世界，我在这里给它留着灯，也偷偷给它攒旅费。”

默认选择一个统一方向直接落地：**温暖、精致、有空间层次的动物生活绘本，带一点旅行杂志的干净排版和轻游戏的互动感。**表现热闹、调皮、亲密；使用原创世界、建筑和角色语言。“疯狂动物城”只用于理解动物社会的丰富性，不复制其中角色、标志或素材。

优先做有构图的 2D / 2.5D 场景：前景植物、中景宠物和互动物件、背景房屋或窗景。暖瓷白、植物绿、少量日光黄与陶土色作为默认基础；夜间延续深暖绿与窗内灯光。沿用并整理语义令牌，避免每个模块自成一套。明信片保持纸张材质。

家园首屏的主角应是场景与宠物，场景约占可用首屏的一半或更多，具体由构图决定。余额、入口和状态围绕场景安排，不能让信息卡把生活场景挤成一个小横幅。

以下不能作为完成标准：仅改配色/圆角/阴影；继续用一排排同尺寸卡片堆功能；把首页做成运营控制台；用 emoji 或几何占位拼出全部主视觉；做华丽静态首页但真实功能无法使用。简洁图标可以用 SVG，主场景需要有完整造型、层次、材质与光线。

先盘点仓库可用素材，再制作缺失的原创场景、植物、物件和状态素材。统一视角、光照和色彩，记录来源与用途；不能随手抓取无授权图片。可用已授权的素材工具；涉及新增付费调用须有相应授权。不为等素材停掉布局、交互和数据接入。不为追求效果强行引入重型 3D 引擎。

### 3. 首先做透三个场景，再统一其余页面

#### A. 共同的家：整个产品的视觉样板

- 房屋/门廊、宠物、菜地、信箱、旅行物件应属于同一空间。收菜、读信、看宠物、准备出发有清晰且可点击的入口；可探索感与可发现性同时成立。
- 菜地显示真实种植状态，播种、成长、成熟、收获有不同表现；点击地块有反馈，结算成功后才显示实际获得物资。旅费、库存和保护状态从服务返回值更新。
- 宠物在家时在场景中有存在感；外出时空间留下空位、行李/便笺等生活线索，同时能方便进入旅途。不能把已在外面的宠物又画成正在家里守菜。
- 可以使用呼吸、摆尾、树叶、窗光、收获等少量动效；未实现动作不能变成诱导点击的假按钮。宠物头像和外貌来自当前宠物，不能所有账号都用同一只样板宠物。
- 农场与邻里要有轻游戏感。保留“偷菜养你”的调皮，但数量、可偷上限、保护和失败原因遵从后端。
- 纪念物能让人读到“这是它带回来的”。暂未支持自由装修就不要做能拖但无法保存的假装修功能。

#### B. 旅途地图：随时看见它正在做什么

- 地图是旅途页主体；车辆沿路线移动，城市、路线、当前位置、目的地和到达时间有清楚层级。不要让大卡片盖住地图主要区域。
- **禁止“同行舱 / 同行仓”和独立交通空间页面。**汽车、飞机、火车、轮船在地图上正常移动；交通工具旁出现音符或小电视；点击图标打开相应播放器，保留地图空间关系。点击车辆打开简洁班次/时间卡。
- 音乐 UI 包含封面、曲名、当前状态和控制，视频 UI 包含真实播放器与收起操作。点击加入后才尝试播放；处理浏览器播放限制、缓冲和失败。暂停影音不暂停旅程；宠物作为驾驶者时不提供视频观看。
- 使用后端时间锚点和世界快照，页面重开仍延续同一旅程。不能为了演示加速正式旅程、随机刷新坐标或伪造已到达。
- 当前没有真实底图能力时，可以把明确标识的示意地图做得精致且可用，同时保留适配边界。坐标、来源和演示性质不能因美化被掩盖；真实高德/Google 接入缺口记录交后端/共享适配器维护者。

#### C. 咖啡馆：让用户看见一次到访

- 通过窗边、桌椅、杯子、灯光、宠物与居民构成明确场景，视觉语言与家园一致。
- 宠物坐下、饮品出现、合影可看见变化，并对应已确认的到访状态。动作结果不只是一条 toast。
- 真实商家名称/分店/资料与动物世界原创内饰区分。用温和可见的说明，不能声称原创内饰就是实店装修。
- 这次到访、地图、私信、照片和公开动态引用同一事件，不在前端自行生成另一个故事状态。

三个场景先形成能运行的完整样板，再铺开：

- **注册与接待**：明确的账号流程；上传或专属领养；有形象、有语气的接待员辅助交代。像认真交付一封叮嘱，支持长文本与可编辑摘要，而非满屏配置项。保留“交给 TA / 只留这里 / 不保存”及细分用途、确认和跳过；不诱导披露，不把规则便笺包装成已连接自由对话 AI。
- **星球圈**：像宠物自己的公开生活动态；照片、正文、角色身份、地点和评论关系有清晰层级。真实账号与星球 NPC 可辨，不伪造热度或陌生人互动。主页和关注/屏蔽/举报等现有行为保留。
- **通讯器**：私密、亲近、可读；突出消息、照片和明信片。根据实际送达/回复状态表达，不制造假“正在输入”。私人叮嘱不得混进公开帖子。
- **寻味**：突出这家分店、这道菜、为何适合、资料来源与未知项。宠物虚拟探店与主人真实评价清楚区分；避免把内部多维评分表直接塞给用户。
- **收藏/仓库/集市/设置**：沿用统一系统，作为次级页面服务主体验。未支持的玩家交易不做成可用操作。

保留四个主入口：**家 / 旅途 / 星球圈 / 通讯**。收藏、集市、仓库与设置走次级入口，控制首页的信息密度。

- 优先 390px，检查 320 / 390 / 430px；平板和桌面重新组织场景与侧栏，不简单把手机页拉宽。文字放大仍可阅读。

- 底部安全区、动态视口、软键盘、返回、刷新深链、弹层关闭/焦点恢复/滚动锁都实际检查。禁止导航遮挡主要按钮和内容。

- 尊重 reduced-motion，控制持续动画与图片体积。保留日夜模式可读性；正文和关键状态不使用低对比度浅灰。
- 内部版本号、契约名、missing_capabilities 等不直接成为产品主文案；转换成简明用户语言。演示线路/示例商家等来源标识必须可见，技术详情可收纳，不可把“演示”藏掉。
