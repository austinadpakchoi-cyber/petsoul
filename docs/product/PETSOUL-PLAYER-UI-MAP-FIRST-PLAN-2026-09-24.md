## 0. 一句话

这是一个像“旅行青蛙”那样的情感疗愈游戏：**打开就是一张真实地图，看见 TA 正在生活**——在家、出门散步、到店坐坐、去打工、回家。所有“正在做什么”都来自后台已经发生的事实。小窝、菜园、驾校是从地图进入的地方；通讯器和回忆是另外两个标签。

## 1. 决定记录

### 1.2 用户对 v1 的五点意见（本版已全部落实）

1. **第一批验收是“看见 TA 在生活”**：能看到散步、到店、打工、回家的状态变化，并能进入小窝再返回地图。只换底图、摆头像达不到要求。→ 第 13 节 批次 1。
2. **活动必须由后台事实决定**：`/friends` 只提供朋友关系，“上次相遇地点”不是实时位置；“准备去打工”不能显示成“正在打工”。需要**统一的世界状态接口**。→ 第 4 节、第 10 节 W1/W2。
3. **首屏再减**：只保留**一张主状态面板**，事件、提醒、点中别的宠物都合进这一张，手机短屏留出地图。→ 第 3 节。
4. **菜园保留、独立推进**：先做土地、作物、批次进度和现有的种 / 收 / 偷；新工具逐批接入。缺水减产、开垦价格未定；**倾向照料奖励，不做“不上线就受罚”**。→ 第 6 节、第 14 节。
5. **先做完整原型，再扩素材**：把“两种风格各三张图”收敛为**一张地图主视觉 + 可点击原型**；方向确认后再让 r7k 做具体素材；地图开发不等农场接口。→ 第 13、15 节。

## 3. 地图首页（一级）：只留一张主状态面板

### 3.1 布局

```text
┌──────────────────────────────────────┐
│ (家)                            (我的) │  ← 左上：进小窝；右上：我的头像
│ (菜)                            (◎)   │  ← 左：菜园；右：定位 TA
│                                 (≡)   │  ← 右：显示范围 附近/全球/朋友/自己
│        ·豆包(打工)                      │
│   ·(到店)      ◉ 小黑(散步)              │  ← 地图尽量多留空间
│        ·(在家)    「海风好轻」             │  ← 同一时间最多一只冒气泡
│                                        │
│┌──────────────────────────────────────┐│
││ ◉ 小黑 · 在白鹭洲散步 · 20 分钟前出门  ≋ ││  ← 唯一的主状态面板（收起约 88px）
││ 有一件事：TA 说想学开车 ›               ││  ← 提醒合进面板，只占一行
│└──────────────────────────────────────┘│
│ (   地图   ·   通讯器   ·   回忆   )    │
└──────────────────────────────────────┘
```

- 首屏只有：地图、左右两列小图标、**一张主状态面板**、底部标签栏。没有左上角宠物小卡、没有单独的事件卡、没有第二张卡。
- 短屏（320×568、375×667）上，面板收起时只占一行主状态 + 一行提醒。

### 3.2 主状态面板的三种状态

| 状态 | 显示 | 交互 |
|---|---|---|
| 默认（收起） | 我的 TA：头像、此刻在干嘛、在哪、从什么时候开始；有提醒时多一行 | 上滑或点开展开 |
| 展开 | TA 现在在干嘛（一段话）、TA 原声 + 翻译、下一站 / 预计何时到、今天路线、明信片、旅行小包、小收藏、收藏攻略、不适合我；所有提醒的列表 | 下滑收起 |
| 点中了别的宠物 | 面板内容**换成那只宠物**：此刻在干嘛、和我的关系、TA 的原声；打招呼、去 TA 家串门、看 TA 的动态；左上角“‹ 回到小黑” | 点“回到小黑”或点地图空白处恢复默认 |

- **提醒**全部合进面板：来信、邀请、菜熟了、驾校进度、TA 想学开车等，按重要程度只显示一条，其余在展开后的列表里。
- 我的 TA **在家**时，面板里有“进小窝”；点地图上的 TA 也直接进小窝。

### 3.3 地图上的宠物

- 每只一个标记：头像 + 状态表情 + 活动角标（在家 / 散步 / 到店 / 打工 / 城里逛 / 出远门 / 回家路上）。
- **头像永远是 TA 自己的样子，不用名字首字**（用户 2026-09-24）：有照片（主人上传或生成的写实照）用照片；演示模式没有照片时用用户授权的内部测试小灰猫；live 没有照片显示中性爪印占位，不借演示猫冒充真实宠物。组件 `features/pets/PetPortrait`。
- **状态表情对所有宠物通用**（用户 2026-09-24：“休息是 zzz，走路能看到是走的动画……一定都是可以复用而不是只给 mock 数据”）：由世界状态的结构化字段 `activity.pose` 决定，不从文字里猜——睡觉冒 z Z z、走路步态加爪印、坐车速度线、店里冒热气、打工 / 张望冒小星星、吃东西碎屑、晒太阳身后的阳光、在家歇着轻轻呼吸；减少动态时只留静态一帧。组件 `features/pets/PetMoodAvatar`，地图标记、主面板、以后的通讯器头部都用它。后端 W1 只给事实能确定的姿态（作息接不上是“歇着”不是“睡觉”；吃饭、晒太阳本批不产出）。
- 我的 TA 带高亮圈；家人的宠物带小房子角标；朋友带小心形角标。
- 世界 → 城市 → 街区三级缩放；远了自动聚合成数字。
- 同一时间最多一只宠物冒实时气泡，来自服务端的最近事实，轮换出现，不刷屏。
- **状态变化看得见**：TA 从家出门时标记沿路移动（在路上阶段按服务端给的路线与进度插值）；到店、开始打工、回家时角标切换，面板文字同步更新，并有轻微的变化动效。

### 3.4 显示范围开关

| 选项 | 显示谁 | 镜头 |
|---|---|---|
| 附近（默认） | 我的 TA 所在城市一带公开的宠物 + 我的 / 家人的 / 朋友 | 城市级，对准 TA |
| 全球 | 全世界公开的宠物（远处聚合） | 世界级 |
| 朋友 | 我的 TA + 家人的宠物 + TA 认识的宠物 | 框住所有朋友 |
| 只看自己 | 我的 TA + 家人的宠物 | 对准 TA |

记住上次的选择。朋友的**位置**只来自世界状态接口；朋友当前不在可见范围时，只在列表里显示“最近见过：某地”，**不在地图上画点**。

### 3.5 隐私

- “我的 → 隐私”：让 TA 出现在附近 / 全球地图上（开关）。
- 在家的宠物只显示到片区（家本来就随机落在某个片区，不是真实地址）；在外面显示到地点级别。
- 面板不显示任何主人信息。
- 可见性的过滤、聚合、缓存都在**服务端**做，前端拿不到不该看的数据（v2.1 补）；**朋友关系不自动授权看位置**，要对方打开“朋友可见”；别人宠物的状态卡只给公开字段（公开名、公开头像、活动种类、模糊位置）。
- “附近”指 TA 家所在片区的周边，不读取主人的真实定位。

## 4. 活动状态：只显示后台事实

### 4.1 规则

- **计划不是正在做**：出行计划、下一站、“准备去打工”只能显示成“准备……”“下一站……”，不能显示成“正在……”。
- **关系不是位置**：`/friends` 里的“上次相遇地点”只能写成“最近在某地见过”，不能当实时位置。
- **没有事实就不猜**：拿不到当前状态时显示“位置未知 / 刚刚还在……”，不从旧数据推断。
- 每条状态都带“从什么时候开始”和事实来源（哪一段路、哪一次到访、哪一个班次），前端不自行拼接或推断。

### 4.2 现在后台已有的事实（仅我的宠物与家人的宠物）

| 事实来源 | 能表达的状态 |
|---|---|
| `/home` 的 `presence` 与 `pets[].presence` | 在家 / 在路上 / 在目的地 / 在店里 / 回家路上 / 未知 |
| `/journey/map` 的每段路 `LegPhase` | 计划中 → 候车 / 登机 → 在路上 → 快到了 → 已到达 / 取消 |
| 当前到访 `current_visit_id` | 在店里坐着（咖啡馆等） |
| `/jobs` 的打工记录 `status` | `going` 去上班路上 / `working` 在干活 / `done` 干完了 |
| 出行意图 `job:` / `route:local:stroll` / `route:local:cafe` / `route:local:city_trip` / `route:long` | 这一趟出门是为了什么（**意图，不等于正在做**） |
| 车上活动 `TravelActivityKind` | 在车上听歌 / 看电视 / 休息 / 看窗外 / 吃饭 / 写明信片 |

这些事实分散在 5 个接口里，别人家的宠物则完全没有。所以需要统一的世界状态接口（第 10 节 W1、W2），由后台一次给出“此刻在干嘛”，前端只负责显示。

### 4.3 地图上的活动角标与文案

| 活动 | 事实条件（由 W1 给出） | 文案示例 |
|---|---|---|
| 在家 | 在家 | 在家打盹 / 在家 |
| 准备出门 | 有已确认的下一趟，尚未出发 | 在家 · 准备去白鹭洲散步 |
| 散步 | 散步这一趟已出发且未结束 | 在白鹭洲散步 · 20 分钟前出门 |
| 在路上 | 在路上阶段 | 坐地铁去中山路 · 预计 15 分钟到 |
| 到店 | 到访进行中 | 在海边咖啡馆坐着 · 刚到 |
| 去打工路上 | 打工记录 `going` | 去书店打工的路上 |
| 打工 | 打工记录 `working` | 在书店打工 · 18:00 下班 |
| 回家路上 | 回家阶段 | 在回家的路上 |
| 未知 | 无事实 | 位置未知 |

## 5. 小窝（二级）

- 满屏场景（庭院 / 屋内），**物件平时不写字**：点一下冒出名字和能做的事，电脑上悬停显示；第一次进来把可点的东西依次轻闪提示一次，之后不再打扰；每个物件都有无障碍名称。
- 物件：TA（陪 TA 待一会儿）、菜园门（→ 菜园）、信箱（→ 通讯器）、收藏柜（→ 回忆）、窝和食盆（后续互动）。
- **返回地图**：左上角返回，回到地图并对准 TA。第一批验收要求“进小窝再返回地图”一气呵成，状态不丢。
- TA 不在家：窝是空的，门口有便笺“我出门啦”，点开回到地图并定位到 TA。

## 6. 菜园（二级）：独立推进

### 6.1 画面

- 开垦出来的土地，**没有木框**；作物画在土里，按阶段变化（种子 → 幼苗 → 长大 → 成熟闪光）。
- 每块种着的地上方有**批次进度条**：阶段 + 剩余时间。进度只用**这一批自己的** `planted_at` / `ripe_at` 与服务器时间计算：进度 =（现在 − planted_at）÷（ripe_at − planted_at）；不能按后来改过的作物配置倒推（v2.1 补，c84a 审阅第 5 条）。`PlotSummary` 目前只有 `ripe_at`，需要后端补 `planted_at`。
- 还没开垦的地是草地，写“开垦”（价格待定，未定前不显示价格也不可点）。
- 仓库篮子、收获飞入篮子、摘菜爪等现有动效保留。

### 6.2 分批

| 批次 | 内容 | 依赖 |
|---|---|---|
| G1 | 土地、作物阶段、批次进度条，接**现有**的种 / 收 / 偷 / 巡院 | 素材（土地、作物阶段）；接口已有 |
| G2 | 浇水（照料奖励：浇过的这批多收一点或提前一点成熟） | 后端规则与接口 |
| G3 | 除草 / 除虫（同样按照料奖励设计） | 后端 |
| G4 | 开垦（地块上限、价格） | 后端定价 |
| G5 | 朋友来帮忙照料（只加好感与照料奖励，不产生收成） | 后端 |

- **照料奖励，不做惩罚**：没照料只是拿不到额外奖励，不减产、不枯死，避免“不上线就受罚”。
- 工具在后端接口就绪前**不出现**（沿用：不做点了没反应的假按钮）。
- 邻居菜园沿用已统一的守护说法：宠物在家是概率保护，不承诺绝对防偷；暂不做“放虫、放草”这类捣乱玩法。

## 7. 通讯器与回忆

### 7.1 通讯器（一级）

- 顶部“小黑的通讯器”：在哪、在干嘛（来自 W1）。
- **通讯**：问问 TA 现在在干嘛，或留一句话（现有）。
- **朋友圈**：我的 TA、家人的宠物、TA 认识的宠物的动态；喜欢 / 摸摸 / 抱抱；顶部“朋友 / 附近 / 全部”筛选（原星球公开动态并入）。
- **TA 的朋友**（新入口，`/friends`）：见过几次、初识 / 熟人 / 好朋友、最近在哪见过（明确写“见过”，不是实时位置）。
- **家庭来信**、**公告**（新入口，`/announcements`）。

### 7.2 回忆（一级）

- **生活片段**（新入口，`/timeline`）：旅行、打工、证件、驾考、朋友、明信片……按时间排列，全部是已经发生的记录。
- 明信片、小收藏、相册、**证件卡包**（见第 19 节）、打工记录、旅程日历与攻略手账。

## 8. 爪爪驾校（二级 / 三级）

后端与前端都已经实现：阶段 `none → wish → enrolled → license_pending → licensed`，四个科目，正式考试每轮首考 + 补考共 2 次、用完有冷却，自由练习不限次，领证仪式，领证后一张借车券（第一次自驾免租车费）。本方案只改**入口和位置**，玩法不变。

### 8.1 什么时候出现

驾校是**主人想帮 TA 拿驾照**时才出现的内容，平时不占首屏：

- **TA 自己想学**（`stage = wish`，带一句 `wish_text`“TA 为什么想学开车”）：主状态面板出现一行“TA 说想学开车……”，通讯器里也有 TA 的这句话。主人点“陪 TA 去驾校”才报名。
- **主人主动**：回忆 → 证件卡包 → 驾照（还没有）→ “陪 TA 去驾校”。
- TA 没表达、主人也没去点时，驾校不出现在地图首屏。

### 8.2 学车中与领证后

- 学车中（`enrolled` / `license_pending`）：主状态面板的提醒行显示进度，例如“驾校 · 科目二可以约考了”“领证仪式在等你们”；证件卡包里显示四个科目的进度。
- 驾校页面（总览、科目、考试、结果、领证仪式、自由练习）是全屏二级 / 三级页，沿用现有页面与考试引擎，视觉随新风格重做。
- 领证后：领证仪式只做一次；驾照进证件卡包；提示借车券；之后 TA 出行可能自己开车，地图上显示“自驾中”（来自行程事实）。
- “主人陪考”的文案沿用；驾照是游戏纪念，不代表现实驾驶资格。

## 12. 地图技术

- **现状**：`src/shared/map/MapSurface.tsx` 是自绘示意图，只在港澳珠三角由后端代理高德**静态**底图，支持不了全球可缩放地图。
- **改为高德 JS API 2.0 可交互地图**：矢量底图、自定义样式、`MarkerCluster` 聚合、低缩放级批量绘制；宠物标记用自定义内容；在路上的宠物按服务端路线插值移动。
- **Key 状态（v2.1 更新）**：本地配置已具备——用户 2026-09-24 提供了“Web 端（JS API）”Key 与安全密钥，存于 git 忽略的 `PetJourneyBackend/data/secrets/web-providers.env`（`AMAP_JS_KEY` / `AMAP_JS_SECURITY_CODE`）；原“Web 服务”Key（`AMAP_API_KEY`）继续给后端用。还没做的：后端正式的配置接口与安全代理（W0）；**域名白名单必须早于任何公网可达的环境**（含临时预览）配好，否则公开返回的 JS Key 等于把额度开放给任何人（总集成提醒，已采纳；需用户的高德账号操作）。
- **安全代理（实测）**：高德要求代理以 `/_AMapService` 作为站点根下的一级路由；不走代理时瓦片能出，但部分样式缺字或空白，所以代理是必需的。浏览器只拿 JS Key，安全密钥永远在服务端。
- **覆盖（实测）**：国内（含港澳）详细。这把 Key **没有境外详细瓦片**（东京、巴黎放大返回 11000 `TILE_ACCESS_OVERSEA_FORBIDDEN`），境外只能看世界级缩放。要看境外城市需另开通高德海外地图权益或另选底图——属于用户决定，未定前“全球”范围里的境外宠物只在世界级缩放出现。正式上线前按高德商用授权条款核对。
- **坐标**：契约统一 WGS-84；画到高德上时前端换算 GCJ-02（与后端 `coords.py` 同一公式），否则偏几百米。
- **样式**：系统浅色 / 深色各一套（`whitesmoke` / `darkblue` 已实测）。深色样式会显示大量真实店名，疗愈感不够；最终需要在高德控制台“自定义地图”做一套安静的样式（少 POI、暖色），这一步要用用户的高德账号，配色以 UI-ASSET-004 主视觉为准。
- **组件位置**：批次 1 原型放在 `src/features/world_map/`（自写加载器，不引 npm 依赖、不改 `package.json`），与现有示意地图 `src/shared/map/` 并存；稳定后再与总集成商量是否提升到 `shared/map`。
